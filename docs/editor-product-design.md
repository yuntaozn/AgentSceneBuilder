# AgentSceneBuilder Editor 产品设计

Editor 是完整的参数化数字建模工作台，不是课件播放器、GLB 查看器或 JSON 调试页。

## 核心工作区

```text
文件与编辑工具栏
├─ 新建、导入、导出、保存
├─ 创建构件
├─ 撤销、重做
└─ 构建与诊断

结构与资源区          模型视图              属性与规则区
├─ 原型树             ├─ 选择与高亮          ├─ 身份与语义
├─ 重复实例           ├─ 变换操纵            ├─ 位置/旋转/缩放
├─ anchor             ├─ 网格/透视/剖切      ├─ 几何和构件参数
├─ attachment         ├─ anchor/路径显示     ├─ repetition
└─ 搜索/过滤          └─ 测量与空间反馈      └─ attachment/约束

状态、诊断与 changeset
```

## 编辑原则

- 编辑参数化原型，展开实例默认只用于选择、检查和定位。
- 修改必须保留 ID、语义、层级、重复规则和连接关系。
- 人工修改与 Agent 修改使用同一种 changeset。
- 删除、改名和改层级前检查引用关系。
- 视图显隐和隔离属于本地工作状态，不直接污染模型数据。
- JSON 是专家入口，不是普通用户的主要编辑方式。

## 功能阶段

### 已实现的编辑器骨架

- 新建、导入、导出和重新构建；
- 创建、复制、删除盒体原型；
- 撤销、重做和快捷键；
- 结构树、搜索、显隐和隔离；
- 模型选择、视角切换、网格、透视和适应窗口；
- anchor 可视化；
- ID、语义、材质、位置、旋转、缩放、尺寸和半径编辑；
- 父节点选择与引用安全删除；
- 基础构件选择器：盒体、板、柱、球体、圆柱体、圆锥体、圆环、管线、网格阵列和空组；
- 材质标识、颜色和不透明度；
- 视图内拖动构件；
- 独立动画面板，以及移动、旋转动画的创建、参数编辑、删除和预览；
- 属性面板使用“组件 ID / 用途分类 / 材质名称”等用户概念，同时标注底层字段名与用途说明；
- 动画目标完全跟随组件树或画布中的当前选择，动画页不维护第二套组件选择器；
- 隔离状态提供视口常驻的“退出隔离”按钮，并支持 Esc 恢复全部组件；
- 画布文本标注的创建、位置和内容编辑；
- JSON 专家编辑和即时诊断。

### 专业空间编辑原型（本轮已实现）

- 结构树以参数化原型为主层，重复展开结果作为 occurrence 子层，空组参与父子层级；
- Ctrl/Cmd 多选原型，按 X、Y、Z 轴对齐或均匀分布；
- 视口提供三轴移动手柄与三轴旋转环，编辑结果回写数字模型参数；
- 三轴旋转环按各自空间平面投影，使用前后半环明暗、轴标签和正方向箭头表达旋转方向；
- 管线路径与 path repetition 显示可拖动控制点；
- attachment 在 anchor 之间显示为带名称的契约连线；
- changeset 页记录编辑摘要、时间与应用状态，并可撤销最近变更。

这些能力当前是轻量 Canvas 交互原型，用于验证编辑语义和操作闭环；正式渲染适配器仍应复用同一套原型、occurrence 与 changeset 数据模型。
