# 教学课件数字模型迁移清单

本清单用于把 历史教学课件 中由代码生成的模型提炼为开放模型库条目。迁移目标是保留参数、语义、空间关系和可编辑结构，不复制课件 UI、步骤动画或 Three.js 对象管理代码。

## 已覆盖类型

- 建筑基础：独立基础、双向钢筋、垫层与边模。
- 建筑构件：装配式保温外墙板及吊点、连接件、灌浆套筒。
- 材料分层：厂房环氧地坪、无机磨石地坪。
- 机电系统：多路径水电管线、管线支吊架、打压测试装置。
- 检测仪器：地坪粘结强度试验体。
- 施工监测：大体积混凝土冷却水管和温度传感器系统。
- 施工机械：履带式挖掘机、装配式墙板运输板车、墙板卸车吊机。
- 空间方法：沿路径重复、锚点连接。

## 后续候选

- 装配式墙板堆放架、运输和吊装场景。
- 施工现场临边防护、机械与巡检点位。
- 机电综合排布中的碰撞、净距与优化前后组合。
- 地坪施工机械和工序影响范围。
- 大体积混凝土测温点、热场分层与时间序列数据绑定。

当前示例库不引入 GLB。施工机械优先迁移课件中的程序化兜底模型，并重建为具有稳定父子层级、关节、锚点和参数的 CompositionSpec。无法脱离特定网格文件表达的对象暂不进入示例库。
